Wobbly guides to the tools developers live in

Learn the command line, git, the web, then security.

Short missions, a sandboxed terminal and a lot of jelly. No install, nothing to break. Start with the shell, because everything else is commands you type into it. Make a web page and put it on the internet. Then learn to think like an attacker, and build things that are hard to break.
