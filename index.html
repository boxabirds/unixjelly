Wobbly guides to the tools developers live in

Learn the command line, git, the web, then security.

Short missions, a sandboxed terminal and a lot of jelly. No install, nothing to break. Start with the shell, because everything else is commands you type into it. Make a web page and put it on the internet. Then learn to think like an attacker, and build things that are hard to break.

Apps hide how computers really work. That's fine, until it isn't. These guides are one place for the basics nobody teaches you: the command line, files and permissions, saving your work with git, how the web works, and how attackers think. They come in order, and every idea is taught before it's used. Free and open source, and they run in your browser: no install, no account, and nothing on your real computer can break. Made for curious kids, about 9 to 14, and grown-ups who never got taught.
